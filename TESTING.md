# Smoke-test checklist — Apeiron Launcher

Используй этот чек-лист перед релизом. Отмечай `[x]` по мере прохождения.

**Среда:** Windows 10/11 x64, чистая папка (или копия лаунчера без `.minecraft` / `config` / `java`).

**Сборки для теста (минимум 4):**

| # | Тип | Пример |
|---|-----|--------|
| A | Vanilla | 1.20.1 |
| B | Fabric | 1.20.1 + Fabric |
| C | Quilt | 1.21 + Quilt |
| D | Forge или NeoForge | любая поддерживаемая версия |

---

## 1. Чистая установка

- [x] Запуск `Apeiron.exe` на чистой машине / в новой папке
- [x] WebView2 доступен (авторизация Microsoft открывается)
- [x] При отсутствии Java — тихая установка Oracle JDK в `Program Files\Java\`
- [x] После установки Java находится через `ResolveJavaPath` (системная установка)
- [x] При ошибке SSL — в консоли видны попытки зеркал; одно из них срабатывает или выводится понятная ошибка
- [x] Папки создаются: `.minecraft`, `config`, `logs`, `instances`

## 2. Создание сборок

- [x] Создать vanilla-сборку (A)
- [x] Создать Fabric-сборку (B)
- [x] Создать Quilt-сборку (C) — переключение лоадеров после Quilt работает
- [x] Создать Forge/NeoForge-сборку (D)
- [x] Фильтр снапшотов в списке версий MC работает
- [x] Переключение RU ↔ EN в настройках — UI обновляется

## 3. Установка и отмена

- [x] Скачивание vanilla (A) — прогресс-бар, консоль, кнопка «Отмена» (закреплена справа)
- [x] Отмена во время загрузки — статус сбрасывается, кнопка «Скачать» снова активна
- [x] Повторная загрузка после отмены — докачивает/устанавливает корректно
- [x] При ошибке установки — диалог «Открыть лог», кнопка «Открыть лог» в статус-баре
- [x] Файл `logs/install-*.log` создаётся при ошибке

## 4. Запуск игры

- [x] Vanilla (A) — игра запускается и доходит до главного меню
- [x] Fabric (B) — запуск без ошибки LWJGL / classpath
- [x] Quilt (C) — запуск OK
- [x] Forge/NeoForge (D) — запуск OK
- [x] Закрытие лаунчера во время игры — Minecraft **не** завершается
- [x] После выхода из игры — кнопка «Играть» снова активна

## 5. Офлайн-режим

- [x] Без входа Microsoft — поле офлайн-ника видно
- [x] Кириллица и спецсимволы **не** принимаются
- [x] Валидный ник (3–16, `a-z`, `0-9`, `_`) сохраняется после перезапуска
- [x] Имя в игре совпадает с офлайн-ником

## 6. Авторизация Microsoft

- [x] Вход через Microsoft — успех, скин загружается
- [x] `config/auth.json` зашифрован (не plain JSON с токеном)
- [x] Перезапуск лаунчера — сессия восстанавливается
- [x] Выход — возврат в офлайн-режим

## 7. Редактор сборки

- [x] Редактирование имени, RAM-настроек сборки (JVM args)
- [x] Моды: список с именами из metadata, вкл/выкл
- [x] Экспорт сборки в zip — без ошибок
- [x] Импорт zip в другую сборку — моды/конфиг на месте
- [x] Переустановка сборки — профиль перекачивается, моды не трогаются

## 8. Настройки и UI

- [x] Настройки: RAM (с учётом памяти ПК), язык, только офлайн, проверка обновлений
- [x] Переключение светлой/тёмной темы
- [x] Консоль: очистка, лимит ~500 строк
- [x] «Открыть логи» в настройках — открывается папка `logs/`

## 9. Повторный запуск

- [x] Перезапуск лаунчера — сборки, настройки, тема, офлайн-ник на месте
- [x] Установленные версии не перекачиваются повторно (быстрый «Играть»)
